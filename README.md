# 🎲 لعبة الدومينو ثلاثية الأبعاد (3D Domino Game)

لعبة دومينو احترافية متكاملة تعمل أونلاين بالوقت الفعلي (Multiplayer) وضد الذكاء الاصطناعي، مصممة خصيصاً للعمل بالوضع العمودي (Portrait) لتقديم أفضل تجربة مستخدم على الهواتف الذكية ومتصفحات الويب.

---

## ✨ المميزات الرئيسية

* **رسومات ثلاثية الأبعاد (3D):** مدعومة بمكتبة Three.js مع إكساءات ديناميكية للقطع.
* **وضع اللعب المزدوج (Multiplayer):** نظام غرف خاص مع كود غرفة، زر للإنشاء، وزر للنسخ المباشر.
* **اللعب ضد الذكاء الاصطناعي (AI):** تحدى الكمبيوتر بذكاء في حال عدم توفر خصم حقيقي.
* **دردشة حية (Chat System):** صندوق محادثة تفاعلي قابل للسحب والإفلات (Drag & Drop) والتصغير داخل شاشة اللعب.
* **نظام القوانين الكامل:** حساب النقاط، كشف حالة "القفلة" (Block)، والوصول إلى الهدف النهائي (100 نقطة).
* **تجاوب تام (Responsive):** مخصصة بالكامل للوضع العمودي لتجنب أي اقتصاص في الشاشة.
* **تأثيرات صوتية:** إدارة متكاملة للصوتيات عبر مكتبة Howler.js.

---

## 🛠️ التقنيات المستخدمة

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Three.js, Howler.js
* **Backend:** Node.js, Express, Socket.io
* **Mobile Packaging (Optional):** Apache Cordova لتصدير اللعبة كتطبيق Android (APK)
